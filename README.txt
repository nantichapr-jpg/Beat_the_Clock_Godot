# Beat the Clock! — Godot 4

## Included
- Godot 4 project
- 6 matching-pair images from the supplied files
- `logo.png`
- Noto Sans Thai Regular font from the supplied ZIP
- English / Thai language toggle
- 30-second, 1-minute, and Infinite modes
- Main Menu, matching logic, timer, win/time-up dialog

## Run in Godot
1. Open Godot 4.
2. Choose **Import**.
3. Select this folder and its `project.godot`.
4. Open the project.
5. Press **F6/F5** or the Play button.

The main scene is `Main.tscn`.
